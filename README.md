# AvDrom

AvDrom — веб‑приложение для размещения и поиска объявлений о продаже автомобилей. Пользователь может зарегистрироваться, войти в систему и публиковать объявления с фотографией и параметрами (марка, модель, цена, год). Доступна фильтрация объявлений на главной странице, добавление в избранное и VIP‑витрина. 

## Целевая аудитория

- Пользователи, которые хотят купить/продать автомобиль через простой каталог объявлений.
- Администратор/модератор, который управляет пользователями и может удалять объявления.

## Ключевой функционал

- Регистрация и вход в аккаунт
- Зона профиля пользователя
- Создание объявлений об авто с загрузкой фото с ПК
- VIP‑объявления
- Избранное: добавление/удаление, просмотр
- Фильтрация объявлений по марке/модели/цене/году.

## Структура приложения

1. Главная (`/`) — публичная, динамический список объявлений + фильтры + VIP‑объявления.
2. Аутентификация (`/auth/*`) — публичная,
   - Вход: `/auth/login`
   - Регистрация: `/auth/register`
   - Выход: `POST /api/auth/logout`
3. Личный кабинет (`/profile`) — приватный раздел (данные пользователя, создание объявлений, избранное).
4. Избранное (в профиле вкладка «Избранное», API `/api/favorites/*`) — приватный.
5. Каталог объявлений (главная + API `GET /api/items`) — публичный список.
6. VIP‑объявления (главная, API `GET /api/items?vipOnly=true`) — публичная.
7. Управление объявлениями (создание/удаление через API) — приватное:
   - `POST /api/items` (только авторизованные)
   - `DELETE /api/items/:id` (владелец или админ)
8. «О нас» (`/about.html`) — публичная информационная страница.

## API

### Auth

- `POST /api/auth/register` — регистрация (name, email, password)
- `POST /api/auth/login` — вход (email, password)
- `POST /api/auth/logout` — выход
- `GET /api/auth/me` — текущий пользователь (id, email, name, role, createdAt)

### Items (объявления)

- `GET /api/items` — список объявлений + фильтры:
  - `brand`, `model`, `minPrice`, `maxPrice`, `year`
  - `favoritesOnly=true` (для авторизованных)
  - `vipOnly=true`
- `POST /api/items` — создать объявление (только авторизованные)
- `DELETE /api/items/:id` — удалить объявление (только авторизованные; владелец или админ)

### Favorites

- `POST /api/favorites/:itemId` — добавить в избранное (только авторизованные)
- `DELETE /api/favorites/:itemId` — убрать из избранного (только авторизованные)
- `GET /api/favorites` — список избранного (только авторизованные)

### Инфраструктура

- **Frontend**:
- HTML — структура страниц  
- CSS — стилизация интерфейса  
- JavaScript — логика на клиенте
- **Backend**: Node.js сервер.
- **База данных**: MySQL
